# MacBook Pro 14 Review

NOTE:  Full disclosure, I am not a professional reviewer, but as an aspiring developer, I’d share my experience with the Macbook Pro after using it for seven months. My work consist of software engineering from the high levels to the low level projects like systems, embedded, and backend.


## Intro
	For years as an undergraduate, I’ve been a Linux user using Fedora as my main distro alongside with Ubuntu and Linux Mint, mainly because I had an easier experience with software development. Especially working with low level projects. But one day in the middle of a semester,  I notice that my laptop runs hot and short of the battery which put me at a desperate position.  After one trip to my local Best Buy and I had my hands on experience with a MacBook Pro 14 (M3 Pro). I’ve kept my older laptop as a fallback if there are any issues I’ve encountered. But after seven months of using it, I’ve decided to compile my thoughts on it and see if it’s worth keeping it.



## Hardware
I’ve picked the M3 Pro given that I have a docking station that has dual monitors and due to having a better GPU dual monitor is possible to use via Thunderbolt 4. I’ve also heard that it included dual fans which made it better for thermals where as the base M3 model was cooled by a single fan. While I’ve tired various laptops through out the years, I think it’s hard to argue with Apple’s hardware. The MacBook has a solid build quality, keyboard and trackpad are enjoyable to use, the screen is great to look at and the battery life endured me through long busy days typically with a few days of uses. 

Now aside with the hardware quality, there are some welcome additions as well having second thoughts. The first part is that the I/O ports had a lot more options compared to the previous ones where it was entirely Thunderbolt. However, this meant that I still need an USB A adapter to use my flash drives as I often store files there and to connect my microprocessor. Another considerations for those who wanted to get a MacBook, think carefully on the storage and memory options as they are not upgradable. I was on the fence if either a 1TB 16GB M3 model or a 512GB 18GB M3 Pro where the base M3 only supports a single external monitor. Along with upgradability, reparability is another issue to face where if it were to break. While there is Apple Care as an option (which I didn’t choose), I felt that wasn’t necessary as I never break a laptop before.
## Software 
I am going to be honest… While I did have an iPhone 15, I never it’s ecosystem features given that I already had a self-hosted solution with Syncthing. While there are a lot of functionalities on macOS that I can take advantage of, most of them are tied to the ecosystem. Since I have a self-hosted file management, I see no use of iCloud where most of the features are tied to their features like Continuity and Handoff. Mainly I prefer things to be separate even though universal clip boards seems useful. As well since I have a linux laptop, I’ve ended up using KDE Connect to transfer files remotely within my home network.  Lastly on the apple ecosystem, I felt that there aren’t many apps that I’ve used like Music, Podcast, or Home, where it could be well considered unnecessary for my workflow. 

With that said, there are some good options for me that I can take advantage of. For example there’s brew; a package manager for macOS so that I can install apps even to where there are no admin privilege needed to install. While the terminal is zsh, navigation is very familiar for me to where I have no problems. But there are a few things that are frustrating for me to use macOS. First was file management on Finder. Where I gotten used to how the gnome file program works where I can navigate with the path, Finder’s navigation feels less intuitive than Gnome’s file manager. As it lacks the path-based browsing (by default) I’ve grown accustomed to. One other example is that I can’t make dot folders on the finder which allows me to make hidden folders. To get that around you can make the folder on the terminal. Another frustrating issue I’ve faced was desktop and window management. In Linux, albeit in Gnome, everything is tied to the super key (or Windows key) where I can see all my windows, switch desktops, and tiling windows. For macOS, I need to learn shortcuts of the same actions which can cause confusion as I often switch computers. 

## Workflow
As I’ve stated that I still kept my old Linux laptop incase if there are some projects that I might run any issues with due to the hardware with ARM and the Software with MacOS. Before that I want to talk about what worked. For app, web, and even some general programming, it works like a charm, especially with how ARM made it faster to compile programs and retaining performance while on battery. The one aspect that is seems easier on a Mac is iOS app development given that it’s of course by Apple. There is also Android Studio for Android apps where I could emulate an Android device without any issues or even to connect my old Pixel phone to get a better testing experience with touch inputs.


Now there are some workflows that I haven’t done yet like data science and machine learning given that it’s not really my specialty. But for low level programming like operating systems and embedded systems, it can be difficult to work with. For embedded I was lucky that MPLABX works but via Rosetta 2; a compatibility layer which helps running old programs (from x86) on the new M-Series Processors. Even so, it might be difficult to develop low level work on a MacBook due to the closed source nature of macOS. 

## Conclusion

Hardware wise, it is the best laptop that I have used in a while, from the keyboard to trackpad, input feels amazing. Battery life gets me through even on the busiest days, and performance is wicked fast. 
There are some limitations with the MacBook’s hardware, despite the welcome changes in the I/O Ports (e.g SD and HDMI). Upgradability and repairability can also be a challenge.
The software meanwhile does have some Unix features that felt familiar to me on the terminal while the file management and the window/desktop management often has it’s shortcomings.

After seven months of using a MacBook Pro, would I recommend it to anyone?  I can’t wholeheartedly recommend the MacBook Pro to those with a similar background as mine, but I won’t warn anyone off either.  If your work is able to benefit with the MacBook’s strength, if you can tolerate the walled-garden of the Apple ecosystem, it is a powerful tool to use. But despite which, the tight ecosystem renowned for it’s convinces is how Apple locks you in to their brand. For those seeking greater control, or a more open environment, then you might want to stay away from it. When buying a MacBook, not only you are getting superb hardware, you’re paying for premium hardware and a tightly integrated ecosystem, but at the expense of openness and control. Untimely the MacBook Pro offers a great combination of hardware prowess and ecosystem integration but requires a willingness to compromise on openness and control.
